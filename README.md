# 🌍 AI Language Translator

An AI-powered multilingual language translation web application built using **Python**, **Streamlit**, **Deep Translator**, and **Google Text-to-Speech (gTTS)**.

The application allows users to translate text between multiple languages instantly through a clean and interactive interface. It also includes speech output, download functionality, and a modern responsive UI for an enhanced user experience.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/YourUsername/CodeAlpha_AI_Language_Translator.git
```

### Navigate into the project

```bash
cd CodeAlpha_AI_Language_Translator
```

### Create Virtual Environment

Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will open automatically in your browser.

---

## 🌟 How It Works

1. Enter the text to translate.
2. Select the source language.
3. Select the target language.
4. Click **Translate**.
5. View the translated text instantly.
6. Listen using Text-to-Speech.
7. Copy or download the translated output.
